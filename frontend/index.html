C Data Structures & Viva Quick Reference

Key concepts used in c-core/calendar.c to explain during your project viva: 

typedef struct {
    int id;                         /* Unique event identifier */
    char title[100];                /* Event title */
    char description[300];          /* Detailed description */
    char date[20];                  /* YYYY-MM-DD */
    char startTime[10];             /* HH:MM */
    char endTime[10];               /* HH:MM */
    char venue[100];                /* Location / Room */
    char category[50];              /* Exam, Assignment, Workshop, etc. */
    char priority[20];              /* High, Medium, Low */
    char reminder[30];              /* Alert duration */
    int isDeleted;                  /* Soft delete flag */
} Event;

/* Functions Implemented in C: */
- addEvent(), updateEvent(), deleteEvent(), getEventById()
- checkConflict(): Overlap check S1 < E2 && S2 < E1
- sortEventsByDateTime(): Ascending sorting using qsort()
- searchEvents(): Case-insensitive substring matching
- loadEvents() / saveEvents(): Binary file I/O with data/events.dat
- calculateStats(): Dynamic dashboard aggregation & day-of-week math
